## 2. Verified P2 findings (should-fix)

### Frontend logic
- **P2-FE-1** SSE reader has no AbortController; two concurrent runs keep two open streams (`stores/app.ts:3320`).
- **P2-FE-2** Poll loops strand on first transient error (sync `1471` / agent `3371`): one blip and the status is stale forever; `startSync` × N spawns N parallel 1 s poll chains.
- **P2-FE-3** `fetchFiles` has no epoch guard (`app.ts:568`); slow `/providers` root browse can resolve after navigation and paint a listing in the wrong directory (`searchFiles` does it right; legacy root-heal `790-804` appends without re-checking `currentPath`).
- **P2-FE-4** `useProviderCanal.ts:249-278` read-modify-write of `vfs:mount:index` unserialized — concurrent save/delete loses mount ids or resurrects deleted mounts.
- **P2-FE-5** `waitBgSettled` (`useAgent.ts:145`) polls unbounded with no per-entry deadline; one hung bg subagent strands the run (should inherit tool-timeout scale + honor fallbackIds).

### Frontend UI/UX
- **P2-UI-1** Crash overlay bricks the session on any stray unhandled rejection (`main.ts` wires `unhandledrejection` to a full-screen alertdialog; no dismiss).
- **P2-UI-2** Three destructive-confirm idioms coexist + one dead ConfirmDialog instance (`App.vue:221`, `confirmVisible` only ever set false) + ~14 `window.confirm` call sites.
- **P2-UI-3** One error → three surfaces (banner + toast + history); banner duplicates toast and lacks `role="alert"` / real dismiss button.
- **P2-UI-4** LandingPage re-mount via `v-if` re-runs the 16-step boot POST and destroys DesktopShell window state on every go_home (`App.vue:943`).
- **P2-UI-5** `refreshAfterSync` leaks one `BroadcastChannel` per sync (`app.ts:1489`, never closed).
- **P2-UI-6** ~2.4k lines dead components: `AgentsWorkspace.vue`, `FaceGroupingPanel.vue`, `HomeCommandBar.vue`, `OrganizePanel.vue`, `SearchMenuWidget.vue`; `ShortcutsHostPanel.vue` wraps `ShortcutsPanel.vue` pointlessly.
- **P2-UI-7** Boot bundle ≈15–16k SLOC eager (SetupWizard 1513, MobileSetupWizard 1156, DesktopShell 1058, TopMenuBar 979, Dock 855, OmniSearchPanel 753…) — no `manualChunks`, no `defineAsyncComponent` for wizard/landing/plasma paths.

### Rust
- **P2-RT-1** `tool_write` (`agent_api.rs:1469-1493`): re-resolution after parent creation is `let _ =` discarded — rename lands on the pre-swap path; the re-check is theater.
- **P2-RT-2** Agent job registry never evicts (`agent_api.rs:1048`, insert-only) — terminal jobs (with transcripts/usage) grow forever on the Docker server; `list_jobs_for` clones every entry then truncates to 50.
- **P2-RT-3** Rate limit is per peer-IP with no `X-Forwarded-For` / trusted-proxy handling — behind Caddy TLS, all tenants share one 100 req/60 s bucket (cross-tenant lockout; the UI's own polls eat the budget).
- **P2-RT-4** `check_access`/`list_visible_files` is O(files × users × perms) with 2–3 read txns per file row (`files.rs:365-456`).
- **P2-RT-5** `bump_vv` (`lease.rs:471`) read-txn → write-txn lost update — same class of bug P0-19 fixed for leases.
- **P2-RT-6** `reject chunked` / non-UTF-8 bodies: `parse_http_request` ignores `Transfer-Encoding: chunked` (empty body → confusing "Invalid JSON" 400) and `.unwrap_or_default()`s binary bodies.
- **P2-RT-7** `transform_payload` (`sync/pipeline.rs:642`) marks incompressible raw bytes as `compressed=true` / bytes_saved 0 — restore compensates, but the no-baseline heuristic path is load-bearing.
- **P2-RT-8** grep/glob agent walkers follow symlinked dirs (`tool_grep`/`tool_glob` — no `symlink_metadata` guard; the kernel's own `resolve()` refuses symlink components, cybsh cat is safe, agent grep is not).

### CLI
- **P2-CLI-1** HEAD-less confirmations: non-interactive `confirmDanger` fails silently ("aborted") and never mentions `--yes`.
- **P2-CLI-2** 15 s hard HTTP timeout on synchronous-but-long ops (`cron run`, batch, snapshot-all, big uploads) with a misleading `network:` message; ignore-`--json` and always-dump-JSON conventions are inconsistent across ~48 commands.
- **P2-CLI-3** `cyb ai prompt --follow` exits on approval park — the CLI is gone when the user approves; no spinner/heartbeat while waiting.
- **P2-CLI-4** `cyb run --json` double-wraps (JSON-in-JSON-string), `cyb serve up` reports success without a readiness dial (Docker path only), Android non-interactive setup dead-ends before validating creds, `doctor` auth probe = full vault listing + HTML landing page counts as PASS.
- **P2-CLI-5** Self-update: SHA256SUMS shares trust anchor with the binary (no signing), rename dance fails on a running Windows exe, no-timeout HTTP clients in update/download, `latestRelease` accepts older tags on dev builds;инг Supabase URL accepted unvalidated (PKCE codes can be pointed at attacker host).

### Ops / CI / release
- **P2-OPS-1** `push.sh --release` creates the tag **before** the rebase onto `origin/main` — tag can point at the pre-rebase commit and ship a stale tree silently.
- **P2-OPS-2** `push.sh --release --last` freshness list omits `dist-ios-device-unsigned` (the artifact most likely missing on a green run) → dispatch burns a release run then fails.
- **P2-OPS-3** Reuse-mode releases skip `docker-build` but the notes still say `docker pull ghcr.io/…:<tag>` (404 / stale `latest`).
- **P2-OPS-4** No job-level `timeout-minutes` anywhere (6 h cap × 15-job matrix).
- **P2-OPS-5** `install.sh` binary replace isn't atomic (cross-FS `mv -f` can destroy an existing `cyb` on disk-full/kill; no `set -o pipefail`); GitHub-API rate limit (60/h/IP) un-retried when resolving `latest`; `--version` not shape-validated.
- **P2-OPS-6** `check-file-headers.sh` enforces “≥2 lines, mentions CyberManju” only — the documented Role/Exports/Integrates keywords are never actually checked.
- **P2-OPS-7** Docs drift everywhere: README says 88/925 tests on line 317 and 25/281 on line 531 (self-contradictory); reality: **267 test files**; 65 components (not 49), 51 composables (not 34), 123 utils (not 67/74), 31 command files (not 26), 41 tables (not 40), 27 api files (not 22), ~183 REST routes (not 170).
